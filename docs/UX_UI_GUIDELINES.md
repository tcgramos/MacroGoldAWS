# UX/UI Profissional

## Visual
- Dark mode institucional (#0B0F19, #121A2B)
- Tipografia de alta legibilidade
- Cores semafóricas consistentes para sinais

## Componentes obrigatórios
- Heatmap de pressão macro
- Velocímetro (Macro Strength Score)
- Radar de correlação
- Cards inteligentes por ativo
- Tabela de alertas com explicabilidade

## Princípios
- 3 segundos para leitura de contexto
- Máximo contraste nos alertas críticos
- Transparência: todo alerta precisa explicar “por quê”
